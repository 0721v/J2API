## 管理员登录

### 访问管理后台

1. 使用管理员账号登录
2. 点击页面右上角「进入后台」或访问 `/admin`

- 控制台：系统运行状态

## 用户管理

### 用户列表

| 功能 | 说明 |
|------|------|
| 搜索 | 支持用户名、邮箱、手机号搜索 |

### 用户操作

| 操作 | 说明 |
|------|------|
| 编辑 | 修改用户信息 |
| 禁用/启用 | 封禁或解封用户 |
| 调整余额 | 增加或扣除用户余额 |
| 调整用户组 | 修改用户权限组 |
| 重置密码 | 强制重置用户密码 |
| 删除 | 删除用户账号 |

### 用户分组

创建和管理用户组，设置不同权限和额度：
- 默认组
- VIP组
- 企业组

## 渠道管理

### 渠道概念

渠道是对接不同AI服务商的通道，例如：
- OpenAI官方渠道
- Azure OpenAI渠道
- Claude渠道
- 自建代理渠道

### 添加渠道

1. 点击「添加渠道」
2. 填写渠道信息：
   - 渠道名称
   - 渠道类型（OpenAI/Claude等）
   - API Endpoint
   - API Key
   - 权重/优先级
3. 设置可用模型
4. 测试连接
5. 保存

### 渠道配置

| 配置项 | 说明 |
|--------|------|
| 基础URL | AI服务API地址 |
| API Key | 访问密钥 |
| 超时时间 | 请求超时设置 |
| 权重 | 负载均衡权重 |
| 状态 | 启用/禁用 |

### 渠道调度

系统支持多渠道负载均衡：
- 按权重分配流量
- 故障自动切换
- 渠道健康检查

## 模型管理

### 模型列表

显示所有可用AI模型：
- 模型名称
- 所属渠道
- 计费类型
- 价格配置
- 状态

### 添加模型

1. 点击「添加模型」
2. 填写模型信息：
   - 模型ID（如 gpt-3.5-turbo）
   - 显示名称
   - 所属渠道
   - 计费类型

### 计费类型

| 类型 | 说明 | 配置项 |
|------|------|--------|
| Token计费 | 按输入/输出Token计费 | 输入单价、输出单价 |
| 按次计费 | 每次调用固定费用 | 每次费用 |
| 按秒计费 | 视频/音频按秒计费 | 每秒费用 |
| 阶梯计费 | 用量越大单价越低 | 阶梯配置 |

### Token计费配置

```
输入价格：¥0.001 / 1K Tokens
输出价格：¥0.002 / 1K Tokens
缓存命中折扣：5折（可选）
```

### 模型倍率

可为不同用户组设置不同倍率：
- 全站倍率：1.0
- VIP组倍率：0.8
- 企业组倍率：0.7

- 支付方式
- 订单金额
- 订单状态

### 订单状态

| 状态 | 说明 |
|------|------|
| 待支付 | 等待用户付款 |
| 已支付 | 付款成功，待确认 |
| 已完成 | 金额已到账 |
| 已取消 | 用户取消订单 |

### 订单处理

- **手动确认**：对于异常订单可手动确认到账
- **退款处理**：为用户办理退款
- **订单导出**：导出订单数据用于对账

|------|-------------|----------|

| 铂金 | ¥200,000 | 15% |

- 查看待结算佣金
- 手动结算佣金
- 查看结算历史
- 处理提现申请

### 提现管理

## 公告管理

### 发布公告

1. 点击「发布公告」
2. 填写公告信息：
   - 标题
   - 内容
   - 类型（重要/警告/通知/信息）
   - 优先级
   - 发布对象
   - 过期时间

### 公告类型

| 类型 | 颜色标识 | 适用场景 |
|------|----------|----------|
| 重要 | 红色 | 紧急通知 |
| 警告 | 橙色 | 需要注意 |
| 通知 | 绿色 | 一般通知 |
| 信息 | 蓝色 | 普通公告 |

### 公告管理

- **草稿保存**：不立即发布
- **定时发布**：设置发布时间
- **历史公告**：查看已过期公告
- **归档**：手动归档公告

## 系统设置

### 基本设置

| 配置项 | 说明 |
|--------|------|
| 网站名称 | 平台显示名称 |
| 网站Logo | 网站Logo |
| 网站描述 | SEO描述 |
| 客服邮箱 | 显示在页面的客服邮箱 |

### 安全设置

- JWT密钥配置
- 登录失败锁定
- IP访问限制
- 注册验证码配置

### 支付设置

#### 支付宝配置

1. 登录支付宝开放平台
2. 创建应用并获取AppID
3. 配置RSA2密钥
4. 填写回调地址

#### 微信支付配置

1. 登录微信商户平台
2. 获取商户号
3. 配置API密钥或证书
4. 填写回调地址

#### Stripe配置

1. 注册Stripe账号
2. 获取API密钥
3. 配置Webhook

#### OKX配置

1. 注册OKX账号
2. 创建API Key
3. 配置提现地址

### 限流设置

| 限制项 | 默认值 | 说明 |
|--------|--------|------|
| 全局限流 | 1000 QPS | 全局每秒请求数 |
| 用户限流 | 60/min | 每用户每分钟 |
| Token限流 | 10000/day | 每Token每日 |

### 邮件设置

配置邮件服务用于发送通知：
- SMTP服务器
- 端口
- 用户名密码
- 发件人地址

### 通知设置

- 余额不足提醒
- 充值到账通知
- 安全告警通知
