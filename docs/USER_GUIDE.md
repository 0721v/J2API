## 快速入门

### 1. 注册账号

访问平台首页，点击「注册」按钮，填写以下信息：

| 字段 | 说明 |
|------|------|
| 用户名 | 3-20个字符，用于登录 |
| 邮箱 | 用于接收通知和找回密码 |
| 密码 | 至少6位字符 |
| 邀请码 | 可选，填写可获得注册奖励 |

注册成功后，系统会自动赠送新用户奖励积分。

### 2. 登录平台

使用用户名或邮箱登录，登录后可访问：
- 控制台：查看账户概览
- API密钥：创建和管理API Key
- 充值：充值余额或购买套餐
- 用量统计：查看API使用情况

### 3. 创建API密钥

1. 进入「API密钥」页面
2. 点击「创建密钥」按钮
3. 填写密钥名称和备注
4. 设置密钥限额（可选）
5. 点击「创建」生成密钥

> **重要**：请妥善保管API密钥，不要泄露给他人。

### 4. 调用API

平台提供OpenAI兼容的API接口：

```bash
# Chat Completions 示例
curl -X POST https://your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-3.5-turbo",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'
```

## API密钥

### 创建密钥

1. 点击「创建密钥」
2. 填写密钥信息：
   - **密钥名称**：用于标识不同密钥
   - **额度限制**：可选，设置总调用额度上限
   - **备注**：描述密钥用途

### 密钥类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 常规密钥 | 常规权限 | 一般应用 |
| 只读密钥 | 仅可查询 | 监控用途 |

### 管理密钥

- **启用/禁用**：临时启用或禁用密钥
- **复制密钥**：点击复制API Key
- **查看统计**：查看该密钥的使用情况
- **删除密钥**：永久删除密钥

### API调用限制

| 限制类型 | 默认值 | 说明 |
|----------|--------|------|
| 每分钟请求数 | 60次 | 防止突发流量 |
| 每日请求数 | 10000次 | 防止过度使用 |
| 单次最大Token | 模型限制 | 输入+输出总和 |

### 调用示例

#### Chat Completions

```python
import requests

url = "https://your-domain.com/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-3.5-turbo",
    "messages": [
        {"role": "system", "content": "你是AI助手"},
        {"role": "user", "content": "你好"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

#### Embeddings

```python
url = "https://your-domain.com/v1/embeddings"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {
    "model": "text-embedding-ada-002",
    "input": "要嵌入的文本内容"
}

response = requests.post(url, headers=headers, json=data)
embedding = response.json()["data"][0]["embedding"]
```

## 常见问题

### API调用问题

**Q: 返回 "Invalid API Key" 错误？**
> 检查API Key是否正确，是否包含空格或特殊字符。

**Q: 返回 "Insufficient Balance" 错误？**
> 账户余额不足，需要充值。

**Q: 返回 "Rate limit exceeded" 错误？**
> 触发了限流，请降低请求频率或申请提高限额。

**Q: 调用超时怎么办？**
> 检查网络连接，或尝试切换到其他渠道。

### 账户问题

**Q: 如何找回密码？**
> 登录页点击「忘记密码」，输入注册邮箱，收到验证码后重置密码。

**Q: 账户被封禁怎么办？**
> 联系客服，提供账户信息查询原因。

**Q: 如何删除账户？**
> 联系平台管理员申请账户注销。

### 充值问题

**Q: 充值未到账？**
> 1. 确认支付是否成功
> 2. 查看是否有支付回调失败
> 3. 联系客服提供支付凭证

**Q: 支持退款吗？**
> 正常情况下不支持退款。如有特殊情况请联系客服。

**Q: 如何开具发票？**
> 联系客服申请开票，提供开票信息和订单号。

- 提交工单：访问「帮助中心」
- 发送邮件：support@your-domain.com
